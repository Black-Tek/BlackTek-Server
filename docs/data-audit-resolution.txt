Data audit resolution
Baseline: 8eb6337c3923ab63c4a5ef2d4a2fa54a132f7b1b

The matrix in data-audit-resolution.json accounts for all 49 original findings.
The original audit targeted the 3dcffcd release snapshot. Current upstream uses
different item and monster APIs and has removed the legacy imbuement shrine.
Findings removed or already corrected upstream are recorded without reviving old code.

Missing content decisions
The unavailable wand, missing minion and off-map raid examples remain disabled.
Three door IDs lack open counterparts and are not registered as keyed doors.
One exceptional keyed door is corrected explicitly. Five broken teleport nodes
were removed, changing only 55 bytes of map data. Their coordinates are listed
in tests/data/README.txt. Restoring these features requires intended content or
destinations from a map/content author.

Verification
Run python tests/data/run.py with Lua 5.3+ and Python 3.11+. The suites compile
and parse the data tree, exercise real Lua callbacks through engine mocks, and
check content and map references. Native compilation, live database behavior
and multiplayer/client tests are separate from these isolated checks.

Deployment
Deploy a rebuilt engine together with the data. Tile:queryAdd and
Player:forgetModalWindow are new bindings; old executables lack them.
Existing player damage from previous bugs is not automatically reversed.
